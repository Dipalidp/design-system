# Design System

A Figma-first, GitHub-backed design system built with AI assistance.

## Structure

| Folder | Contents |
|---|---|
| `/tokens` | Design tokens — color, spacing, typography, shadows |
| `/components` | UI components with usage notes and Figma links |
| `/pages` | Full page templates and layout patterns |
| `/docs` | Design principles, contribution guidelines, accessibility notes |

## Tools & Stack

- **Figma** — source of truth for design
- **GitHub** — version control for tokens, components, and docs
- **Claude** — AI assistant for documentation and copy
- **Figma GitHub Plugin** — syncs Figma files to this repo

## Getting Started

1. Clone this repo
2. Open the linked Figma file (see `/docs`)
3. Follow contribution guidelines in `/docs/contributing.md`
